ifetch help page

Usage: ifetch

Example: ifetch -v

Options:
    <config path>
        use a custom configuration file
    
    -p, --presets
        shows all installed presets

    -h, --help
        shows this help page

    -v, --version
        shows current version of ifetch

Files:
    /etc/ifetch/presets/
        system-wide ifetch presets
    
    /etc/ifetch/ifetch.config
        system-wide configuration file

    ~/.config/ifetch/ifetch.config
        users configuration file - empty by default

    /etc/ifetch/logo.txt
        system-wide ifetch logo

    ~/.config/ifetch/logo.txt
        users ifetch logo - empty by default

    /etc/ifetch/help.txt
        ifetch help page

    /etc/ifetch/modules/
        modules like user.sh, logo.sh and more

Configuration: module=<name> <options>

Example: module=ram -g --color green

Modules:
user
    shows current user

hostname
    shows the system hostname

kernel
    shows the Linux kernel version

logo
    displays the ASCII logo in /etc/ifetch/logo.txt

shell
    shows the current used shell

timezone
    shows the timezone of the system

language
    shows the language of the system

os
    shows the OS name

uptime
    shows how long the system has been running

ram
    shows RAM usage of the system
    Option: -g to show it in GB instead of MB

disk
    shows disk usage
    Option: -t to show it in TB instead of GB

cpu
    shows the CPU name

network
    shows the local-ip of the system

separator
    creates a separator line

echo
    prints a custom message
    module=echo "I Love Linux" --color blue

command
    run a custom command
    module=command "cd && cd .."

temperature
    shows the current temperature of the system

weather
    shows the current weather of a city in °C
    module=weather <city>

crypto
    shows the price of a cryptocoin in $
    module=crypto <cryptocoin>

process
    shows the total number of processes currently running

packages
    shows the total installed packages, supported package managers: dpkg apk pacman emerge

tty
    shows the current tty

dns
    shows the dns of the system

Colors: black red green yellow blue mangenta cyan white
